# Problems

Individual C++ exercises, grouped by topic in learning order. Every file is a
standalone program that can be opened in any C++ compiler.

| Topic | Files | What it covers |
|---|---|---|
| `01_Basics` | 8 | Variables, arithmetic, console I/O, type conversions, circle-area formulas, first "Hello World" |
| `02_Control_Flow_Loops` | 16 | if/else, enums in switches, `for`/`while`/`do-while`, number ranges, sum/pattern loops |
| `03_Functions` | 5 | Calling functions, returning values, factorial, power, swap |
| `04_Structs_Enums` | 14 | Structs, enums + switch, employees, piggy-bank, random char/keys |
| `05_Arrays` | 19 | Filling, printing, averaging, searching, copying, shuffling, primes |
| `06_Matrices` | 20 | The `#3` problem set (problems 1–20): sums, transpose, equality, identity, sparse, palindrome |
| `07_Strings` | 9 | The `#3` string problems (23–35): first letters, case, counting, vowels, splitting |
| `08_Recursion` | 2 | Fibonacci — array version then recursive version |
| `09_Date_Time` | 3 | Date display, a period library (`54#3`), a full date library (`MathLib`) |
| `10_File_IO` | 4 | File write/read learning steps (`.cxx`) that prepare the level-7 project |
| `11_Data_Structures` | 1 | Custom doubly linked list |
| `12_OOP` | 5 + 3 | Calculator, Address and Person classes; plus class-library folders (`string_class_library`, `date_string_demo_class`, `template_class`) |

## Note on problem numbering

Problems `#3`/`#2` keep their original course numbers (`Problem_01`, ...) so
the progression from the source course is preserved. `_v2`/`again` suffixes
mark a second attempt at the same problem.
