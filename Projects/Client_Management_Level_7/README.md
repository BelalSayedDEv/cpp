# Client Management — Level 7

The **level-7 course project**: a client management program that reads and
writes client records to a text file.

## Features

* **Main menu**:
  1. Show client list
  2. Add new client
  3. Delete client (removes the record from the file)
  4. Update client info
  5. Find client
* **File persistence** — clients saved to `client.txt` (kept as a sample).

## How to run

Open `Client_Management_Level_7.sln` in Visual Studio 2022, build for
**x64 / Debug**, and run.
