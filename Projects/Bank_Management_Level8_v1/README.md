# Bank Management — Level 8 (First Version)

The **first version** of the level-8 course project. A single-file bank
management program that reads and writes client records from a text file.

## Features

* **Main menu**:
  1. Show client list
  2. Add new client
  3. Delete client
  4. Update client info
  5. Find client
  6. Transactions
* **Transactions** — deposit / withdraw.
* **File persistence** — clients saved to `member.txt` / `myfile.txt`
  (kept as samples).

## How to run

Open `Bank_Management_Level8_v1.sln` in Visual Studio 2022, build for
**x64 / Debug**, and run.

## Note

This version predates the login/users feature. The improved successor is
[`Bank_Management_Level8_v2`](../Bank_Management_Level8_v2/) — both were kept
to show the development progression.
