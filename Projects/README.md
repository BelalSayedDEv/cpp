# Projects

Complete, runnable programs. Each is a full Visual Studio project — open the
`.sln` (or the `.vcxproj` for the OOP bank system) in Visual Studio 2022 and
build for **x64 / Debug**.

| Project | Description |
|---|---|
| [`Bank_System_OOP`](Bank_System_OOP/) | Multi-file **OOP bank system**. Login screen, clients & users management, permissions, deposits/withdrawals/transfers, currency exchange, and action logs. Built from ~35 class headers (`cls*`). |
| [`Bank_Management_Level8_v2`](Bank_Management_Level8_v2/) | Level-8 final project, **final version**. Menu-driven bank client management with a **login system**, client CRUD, transactions, and **user management with permissions**. Single file + file persistence. |
| [`Bank_Management_Level8_v1`](Bank_Management_Level8_v1/) | Level-8 final project, **first version** (kept to show the progression). Client list/add/delete/update/find + transactions, saved to a file. |
| [`Client_Management_Level_7`](Client_Management_Level_7/) | Level-7 final project. Client management (list, add, delete/archive, update, find) persisted to `client.txt`. |

Each project folder has its own README with details on what it does and how
to run it.
